# دليل استخدام موفو

[English](USER_GUIDE.md)

## 1. التثبيت

### ويندوز 10 / 11
1. نزّل ملف **Movo-Setup-x.y.z.exe** من صفحة الإصدارات وشغّله (لا يحتاج صلاحيات المسؤول).
   أو نزّل النسخة المحمولة **Movo-Windows-x64-portable.zip**، ثم انقر بزر الماوس الأيمن ← *استخراج الكل*، وافتح `Movo.exe`.
2. إذا ظهرت رسالة *«حماية Windows لجهازك»* اضغط **مزيد من المعلومات ← التشغيل على أي حال**.

### ماك (macOS 12 أو أحدث)
1. نزّل ملف `.dmg` المناسب لجهازك (**arm64** لمعالجات Apple و**x86_64** لمعالجات Intel)، وافتحه واسحب **Movo** إلى **التطبيقات**.
2. افتح التطبيق. إذا ظهر أن النظام لا يستطيع التحقق منه، افتح **إعدادات النظام ← الخصوصية والأمان** واضغط **الفتح على أي حال**.
3. اسمح بالوصول إلى **الكاميرا**.
4. إذا ظهر شريط أصفر، اضغط **فتح الإعدادات** وفعّل التطبيق في **تسهيلات الاستخدام**، ثم أغلق التطبيق وافتحه من جديد.
5. للقطات الشاشة اسمح أيضًا بـ **تسجيل الشاشة**.

### لينكس
- **AppImage**: `chmod +x Movo-Linux-x86_64.AppImage && ./Movo-Linux-x86_64.AppImage`
- يعمل بأفضل شكل على **X11**. على Wayland تحتاج اختصارات لوحة المفاتيح إلى `ydotool`.

### أندرويد 8 أو أحدث
1. ثبّت ملف **Movo-Android.apk**.
2. افتح التطبيق واضغط زر التشغيل، واسمح بالكاميرا والإشعارات.
3. اضغط **تفعيل** في بطاقة *التحكم في الهاتف*، واقرأ كيف يستخدم التطبيق تسهيلات الاستخدام، ثم فعّل **التحكم بالإيماءات - موفو**.

### آيفون / آيباد
لا تسمح iOS للتطبيقات بالتحكم في تطبيقات أخرى، لذلك يتحكم التطبيق على iOS في **العارض** الخاص به (ملفات PDF والصور)، ويمكن استخدامه **ككاميرا عن بُعد** لحاسوبك.

## 2. التشغيل لأول مرة

تختار في شاشة الترحيب **اللغة** (العربية / English) و**السمة** (فاتحة / داكنة / حسب النظام)، ثم تتعرّف على الخصوصية وأول الإيماءات.
اضغط **زر التشغيل** الكبير للبدء، واضغط مرة أخرى للإيقاف.

- **الإيقاف المؤقت** دون إيقاف التطبيق: زر *إيقاف مؤقت*، أو إيماءة 🤘 (مع الثبات قليلًا)، أو قائمة شريط المهام، أو **Ctrl + Alt + G**.
- إغلاق النافذة يُبقي التطبيق يعمل في شريط المهام. للخروج اختر **الخروج من موفو** من قائمة الأيقونة.

## 3. الإيماءات

اثبت على كل إيماءة لحظة، وأبقِ يدك على بُعد 40–100 سم من الكاميرا وكفّك نحوها.

| الإيماءة | الإجراء الافتراضي |
|----------|-------------------|
| 👍 رفع الإبهام (مع الثبات) | رفع الصوت بشكل متواصل |
| 👎 خفض الإبهام (مع الثبات) | خفض الصوت بشكل متواصل |
| 👉 / 👈 الإشارة يمينًا / يسارًا | التالي / السابق — للشرائح والصور والفيديو |
| 🤏 قرص سريع | تشغيل / إيقاف |
| ☝️ السبابة للأعلى ثم التحريك | التمرير — كلما ابتعدت زادت السرعة |
| 🤏 قرص مع الثبات ثم التحريك | تكبير / تصغير |
| ✋ سحب لليمين / لليسار | علامة التبويب التالية / السابقة |
| ✌️ علامة النصر | لقطة شاشة |
| 🤙 علامة الاتصال | تشغيل / كتم الميكروفون |
| ✊ قبضة | تخطي الإعلان |
| 🤘 علامة الروك (ثانية تقريبًا) | إيقاف / استئناف التطبيق |

**إيماءات الرأس**: الإيماء = تشغيل/إيقاف، هزّ الرأس = تخطي الإعلان، الإمالة يمينًا/يسارًا = التالي/السابق،
النظر للأعلى/للأسفل = التمرير، الالتفات يمينًا/يسارًا = علامة التبويب التالية/السابقة.
وفي **الوضع الدقيق**: فتح الفم = الميكروفون، الابتسامة = لقطة شاشة.
اضغط **إعادة معايرة الرأس** وأنت تنظر مباشرة إلى الشاشة إذا شعرت أن الإيماءات غير دقيقة.

### تغيير ما تفعله الإيماءة
من صفحة *إيماءات اليد* أو *إيماءات الرأس* اختر الملف الشخصي ثم الإجراء من قائمة **تقوم بـ**.
اختر **اختصار مخصّص…** لإرسال أي مجموعة مفاتيح مثل `ctrl+shift+m`.

### وضع التدريب
الرئيسية ← *وضع التدريب*: يعرض التطبيق الإيماءة التي يراها دون تنفيذ أي إجراء.

### إيماءات العين (مع النظارة أو بدونها)
افتح **إيماءات العين** وفعّلها، وإن كنت ترتدي نظارة ففعّل **أرتدي نظارة**، ثم اضغط **معايرة عينيّ**
(7 ثوانٍ: انظر إلى الشاشة ثم أغمض عينيك بين صوتين) — وأنت ترتدي نظارتك وتجلس كعادتك.

| إيماءة العين | الإجراء الافتراضي |
|--------------|-------------------|
| 😉 غمزة يسرى / يمنى | السابق / التالي |
| 👁️ رمشة مزدوجة | تشغيل / إيقاف |
| 😌 رمشة طويلة (ثانية) | تخطي الإعلان |
| 😴 إغماض العينين ثانيتين | إيقاف / استئناف التطبيق |
| 🔼 / 🔽 النظر للأعلى / للأسفل مع الثبات | التمرير |

لا يؤدي الرمش الطبيعي إلى أي إجراء. لا تستطيع الغمز؟ استخدم الرمشة المزدوجة والطويلة.

## 4. الملفات الشخصية
إعدادات مختلفة لتطبيقات مختلفة: **عام**، **عرض تقديمي**، **وسائط**، **المتصفح**، **اجتماع**.
عند تفعيل *التبديل التلقائي* يستخدم التطبيق الملف المناسب للتطبيق الظاهر أمامك.

## 5. تخطي الإعلانات
إيماءة ✊ تضغط زر **تخطي** الظاهر. لأفضل نتيجة ثبّت **مساعد المتصفح** من الإعدادات ← التكاملات ← *طريقة التثبيت*.

## 6. الهاتف ككاميرا عن بُعد
1. على الحاسوب: الإعدادات ← التكاملات ← فعّل **استخدام هاتفي ككاميرا عن بُعد**.
2. على الهاتف: امسح رمز QR بالكاميرا (أو أدخل العنوان والرمز في صفحة *التحكم عن بُعد*)، ثم فعّل **إرسال الإيماءات إلى الحاسوب**.
3. شغّل التطبيق على الهاتف. تُرسَل أسماء الإيماءات فقط عبر شبكة Wi-Fi — وليس الفيديو.

## 7. حل المشكلات

| المشكلة | الحل |
|---------|------|
| تعذّر فتح الكاميرا | أغلق Zoom أو Teams أو تطبيق الكاميرا، أو اختر كاميرا أخرى من الإعدادات |
| المفاتيح لا تصل إلى التطبيق | انقر على النافذة المطلوبة مرة واحدة؛ وعلى ماك فعّل تسهيلات الاستخدام وأعد التشغيل |
| إجراءات غير مقصودة كثيرة | زِد مدة الثبات، أو أوقف الإيماءات غير المستخدمة، أو استخدم 🤘 للإيقاف المؤقت |
| لا يتعرّف على الإيماءات | أضف إضاءة أمامك، وأبقِ اليد كاملة داخل الصورة، وتجنّب الإشارة المائلة |
